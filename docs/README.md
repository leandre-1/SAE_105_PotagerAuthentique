# Potager Authentique – Documentation

Bienvenue dans la documentation du projet Potager Authentique Template.

## Contenu

- **Structure du projet** : Présentation rapide des répertoires et fichiers clés.
- **Style et assets** : Emplacement des feuilles de style, polices et images.
- **Pages** : Aperçu des pages principales (index, Produit-du-potager, Qui-sommes-nous).

## Structure

- `index.html` : Page d’accueil avec la mise en avant des produits.
- `Produit-du-potager.html` : Catalogue des produits.
- `Qui-sommes-nous.html` : Présentation de l’équipe et de la démarche RSE.
- `assets/` : Ressources partagées (CSS, polices, images).
- `docs/` : Ce dossier de documentation.
